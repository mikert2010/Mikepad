# Mikepad

Mikepad is a small dark-sepia Windows text editor inspired by Windows 98 Notepad.

## Download

Download [Mikepad.zip](Mikepad.zip), unzip it, and run `Mikepad.exe`.

Windows may show a warning because this app is not code-signed. Choose "More info" then "Run anyway" if you trust this download.

## Notes

- One text file per window
- Open, save, and save as
- Word wrap toggle
- Dark sepia editor with custom scrollbars

The app icon is embedded inside `Mikepad.exe`.
